# TAY Health Directory: Local Healthcare Website

A responsive healthcare directory website that helps visitors find doctors and hospitals in their area, with a clean and easy to use layout.

**Live demo:** https://shiny-alpaca-54129e.netlify.app

## Pages

**Home:** overview of the directory and its main services.

**Find Doctor:** browse and search doctors.

**Find Hospital:** browse hospitals with their details.

**Contact Us:** contact form and information.

## Tech Stack

HTML5 | CSS3 | Bootstrap

## Project Structure

The root folder holds the four HTML pages. The `CSS` folder holds the custom styles, the `Bootstrap` folder holds the Bootstrap stylesheet, and the `Images` folder holds the images used across the site.

## Run Locally

Download or clone this repository and open `index.html` in any modern browser.
